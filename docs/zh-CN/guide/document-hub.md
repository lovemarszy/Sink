# Document Hub

The fork-specific guide is currently maintained in English. Read the [Document Hub guide](/guide/document-hub) and the repository's `DOCUMENT_HUB.md` for directory access, independent management authentication, the minimal deployment profile, and maintenance.

The other pages in this documentation tree describe inherited Sink features. Analytics, Workers AI, R2 backups, and public previews are disabled by the Document Hub minimal profile.
